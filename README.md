# Репозиторий пакетов ShidikusikOS

Обновляется автоматически при сборке. Подключение:

    echo "deb [trusted=yes] https://raw.githubusercontent.com/shidikusik/ShidikudikOS/apt-repo ./" | sudo tee /etc/apt/sources.list.d/shidikusik.list
    sudo apt update && sudo apt install shidikusik-desktop

Проще: sudo shidik-update в самой системе.
