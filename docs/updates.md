# Обновление ShidikusikOS без переустановки

Короткий ответ: **«Настройки → Обновления → Обновить ShidikusikOS»** или
в терминале:

```sh
sudo shidik-update
```

Одна команда обновляет и Debian-пакеты, и само рабочее окружение
(ShidikDM, композитор, панель, шторку, все приложения). После обновления
достаточно выйти из сессии (Win+Esc) или перезагрузиться — переустановка
системы не нужна.

## Как это устроено

Рабочее окружение — это обычный пакет **`shidikusik-desktop`**, а не
россыпь файлов:

```
CI (GitHub Actions)
 ├── собирает shidikusik-desktop_1.0.<дата>_amd64.deb
 ├── кладёт его в ветку apt-repo вместе с Packages/Release
 └── собирает ISO, внутри которого этот же пакет уже установлен

Ваш компьютер
 └── /etc/apt/sources.list.d/shidikusik.list
      deb [trusted=yes] https://raw.githubusercontent.com/shidikusik/ShidikudikOS/apt-repo ./
```

`apt` видит новую версию так же, как обновления любого другого пакета:

```sh
sudo apt update
apt list --upgradable        # в списке будет shidikusik-desktop
sudo apt upgrade
```

`shidik-update` делает то же самое плюс мелочи: подключает репозиторий,
если его нет, и переводит окружение под управление apt на системах,
установленных со старых образов.

## Версия окружения

```sh
dpkg-query -W -f='${Version}\n' shidikusik-desktop
```

Она же показана в «Настройки → Обновления». Формат — `1.0.ГГГГММДДЧЧММ`
(время сборки в UTC), поэтому более свежая всегда «больше» для apt.

## Если система установлена со старого образа (dev-r10 и раньше)

В тех образах окружение ставилось файлами, apt о нём не знал. Достаточно
один раз выполнить:

```sh
sudo shidik-update
```

Скрипт подключит репозиторий и поставит пакет поверх — дальше обновления
пойдут штатно. Если `shidik-update` в системе ещё нет:

```sh
echo 'deb [trusted=yes] https://raw.githubusercontent.com/shidikusik/ShidikudikOS/apt-repo ./' \
  | sudo tee /etc/apt/sources.list.d/shidikusik.list
sudo apt update && sudo apt install shidikusik-desktop
```

## Запасной путь: сборка из исходников

Если репозиторий недоступен (нет сети до GitHub, свой форк, правки в
коде):

```sh
sudo shidik-update --from-git
```

Скрипт поставит инструменты сборки, склонирует репозиторий, соберёт и
установит окружение. Работает всегда, но занимает несколько минут и
оставляет в системе dev-пакеты.

## Откат на предыдущую версию

В репозитории хранятся три последние сборки:

```sh
apt list -a shidikusik-desktop           # доступные версии
sudo apt install shidikusik-desktop=1.0.202607251230
```

## Честно о подписи репозитория

Репозиторий подключён с флагом `[trusted=yes]` — пакеты **не подписаны
GPG-ключом**. Это осознанный компромисс: подпись требует хранить
приватный ключ в секретах CI и настраивать его вручную, а трафик и так
идёт по HTTPS с github.com.

Практический риск: если кто-то получит доступ к репозиторию на GitHub,
он сможет подсунуть пакет, который выполнится с правами root при
обновлении. Для личного дистрибутива это приемлемо; для раздачи
посторонним людям репозиторий стоит подписать (`apt-ftparchive` +
`gpg --clearsign` Release, публичный ключ в `/etc/apt/trusted.gpg.d/`).

## Что обновляется, а что нет

| Что | Как обновляется |
|---|---|
| Рабочее окружение (наш код) | пакет `shidikusik-desktop` |
| Ядро, драйверы, прошивки, браузер, все программы Debian | обычный `apt upgrade` |
| Приложения из Flathub | `flatpak update` |
| Разметка диска, пользователи, ваши файлы | не трогаются вообще |
